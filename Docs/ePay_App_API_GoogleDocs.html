ePay India - Mobile App API

API for every web app page, from Login to Account Delete

API Details

ItemValue
URLhttps://epayindia.in/AppApi.aspx
MethodPOST
HeaderContent-Type: application/json
LoginSend userid and passwd (website login) in every API call. Only couponlist and monthlypackages do not need them.

Response Format

FieldMeaning
responseOK / FAILED
codeSee the code table below
msgMessage to show to the user
reqtypeThe reqtype that was sent
reqidUnique ID of the call - share this with support if there is a problem
dataResult object (null when FAILED). Amounts are numbers, e.g. 1250.00
CodeMeaning / What the app should do
200Success
400Invalid input or business rule failed - show msg
401Wrong userid / passwd - clear the saved login and open the Login screen
403ID is blocked - show msg and log out
404Package / order not found - show msg
409Same request received again within 20 seconds - show msg, try again after a moment
500Server error - offer a retry and share reqid with support

Failed Response Example

{
    "response": "FAILED",
    "code": 400,
    "msg": "Insufficient Balance!!",
    "reqtype": "couponpurchase",
    "reqid": "20260924153101874021",
    "data": null
}

22. Petro Card Purchase API

reqtype: petrocardpurchase

Request

{"reqtype":"petrocardpurchase","userid":"EPI123456","passwd":"EPI@123456","kitid":12,"paymentmode":"WALLET","wallettype":"S","gender":"M","dob":"15-Aug-1990","email":"member@example.com","mobile":"9876543210","whatsappno":"9876543210","panno":"ABCDE1234F","address":"12, MG Road","pincode":"302001","statecode":"8","city":"Jaipur","district":"Jaipur"}

Response

{
    "response": "OK",
    "code": 200,
    "msg": "Petro Card Purchase Successfully.!",
    "reqtype": "petrocardpurchase",
    "reqid": "20260924190310889900",
    "data": {
        "paymentmode": "WALLET",
        "billno": "518342",
        "kitid": 12,
        "kitname": "PETRO CARD SILVER RS. 5000/-",
        "amount": 5000.00,
        "walletbalance": 7500.00
    }
}

Notes

  • paymentmode = WALLET (instant purchase from wallet; wallettype is required) or PG (UPI payment gateway).
  • For PG, the response contains orderid and paymenturl. Open paymenturl in a WebView; when it reaches PETROCARDPurchase.aspx, close it and call the Payment Status API (ordertype = PETROCARD).
  • dob format is dd-MMM-yyyy (e.g. 15-Aug-1990). statecode and gender come from the Petro Card Form API.
  • The server takes the amount from the database. The same request again within 20 seconds returns code 409.
