ePay India - Mobile App API

Webapp ke saare pages (Login se Account Delete tak) ki API

API Details

ItemValue
URLhttps://epayindia.in/AppApi.aspx
MethodPOST
HeaderContent-Type: application/json
LoginHar API mein userid aur passwd zaroori (website wala login). Sirf couponlist aur monthlypackages mein nahi chahiye.

Response Format

FieldMatlab
responseOK / FAILED
codeNeeche wali table dekho
msgUser ko dikhane wala message
reqidProblem aaye to support ko yahi number do
dataResult (FAILED par null). Amount number mein aata hai, jaise 1250.00
codeMatlab / App kya kare
200Success
400Galat input ya rule - msg dikhao
401Galat userid / passwd - saved login hatao, Login screen par bhejo
403ID block hai - msg dikhao, logout karo
404Package / order nahi mila - msg dikhao
409Same request 20 second ke andar dobara aayi - msg dikhao, thodi der baad try
500Server error - retry ka option do, support ko reqid do

Failed Response Example

{
    "response": "FAILED",
    "code": 400,
    "msg": "Insufficient Balance!!",
    "reqtype": "couponpurchase",
    "reqid": "20260924153101874021",
    "data": null
}
