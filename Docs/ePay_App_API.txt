ePay India - Mobile App API Document

URL : https://epayindia.in/AppApi.aspx
Method : POST
Header : Content-Type: application/json

Note  har API mein userid aur passwd bhejna zaroori hai (website wala login).
      Sirf couponlist aur monthlypackages mein userid / passwd nahi chahiye.

Note  har response mein ye fields aati hain :
      response = OK / FAILED
      code     = 200 success, 400 galat input ya rule, 401 galat userid / passwd (Login screen par bhejo),
                 403 ID block, 404 nahi mila, 409 same request 20 second mein dobara, 500 server error
      msg      = user ko dikhane wala message
      reqid    = problem aaye to support ko yahi number do
      data     = result (FAILED par null)

Note  amount number mein aata hai (string nahi), jaise 1250.00

Failed Response Example :
{"response":"FAILED","code":400,"msg":"Insufficient Balance!!","reqtype":"couponpurchase","reqid":"20260924153101874021","data":null}
