ePay India - Mobile App API Document

URL : https://epayindia.in/AppApi.aspx
Method : POST
Header : Content-Type: application/json

Note : Send userid and passwd (website login) in every API call.
       Only couponlist and monthlypackages do not need userid / passwd.

Note : Every response contains these fields:
       response = OK / FAILED
       code     = See the code table below
       msg      = Message to show to the user
       reqtype  = The reqtype that was sent
       reqid    = Unique ID of the call - share this with support if there is a problem
       data     = Result object (null when FAILED). Amounts are numbers, e.g. 1250.00

Response codes:
       200 = Success
       400 = Invalid input or business rule failed - show msg
       401 = Wrong userid / passwd - clear the saved login and open the Login screen
       403 = ID is blocked - show msg and log out
       404 = Package / order not found - show msg
       409 = Same request received again within 20 seconds - show msg, try again after a moment
       500 = Server error - offer a retry and share reqid with support

Failed Response Example:
{"response":"FAILED","code":400,"msg":"Insufficient Balance!!","reqtype":"couponpurchase","reqid":"20260924153101874021","data":null}
