ePay India - Mobile App API Document

URL : https://epayindia.in/AppApi.aspx
Method : POST
Header : Content-Type: application/json
         apikey: <apikey from the Login response>   (only when islogin = "Y")

Note : Send userid and passwd (website login) in every API call.
       Only couponlist and monthlypackages do not need userid / passwd.

Note : Send "islogin" in every API call:
       islogin = "N" (no apikey header) : login, couponlist, monthlypackages
       islogin = "Y" (apikey in header)  : all other APIs
       A wrong islogin value returns code 400.

Note : The Login API returns a new "apikey" every time you log in. Save it and send it
       in the "apikey" header of every islogin = "Y" call. The old apikey stops working
       after a new login or a logout.

Note : Every response contains these fields:
       response = OK / FAILED
       code     = See the code table below
       msg      = Message to show to the user
       reqtype  = The reqtype that was sent
       reqid    = Unique ID of the call - share this with support if there is a problem
       data     = Result object (null when FAILED). Amounts are numbers, e.g. 1250.00

Response codes:
       200 = Success
       400 = Invalid input or business rule failed - show msg
       401 = Wrong userid / passwd, or apikey missing / expired - clear the saved login and open the Login screen
       403 = ID is blocked - show msg and log out
       404 = Package / order not found - show msg
       409 = Same request received again within 20 seconds - show msg, try again after a moment
       500 = Server error - offer a retry and share reqid with support

Failed Response Example:
{"response":"FAILED","code":400,"msg":"Insufficient Balance!!","reqtype":"couponpurchase","reqid":"20260924153101874021","data":null}

Request:
{"islogin":"Y","reqtype":"petrocardpurchase","userid":"EPI123456","passwd":"EPI@123456","kitid":12,"paymentmode":"WALLET","wallettype":"S","gender":"M","dob":"15-Aug-1990","email":"member@example.com","mobile":"9876543210","whatsappno":"9876543210","panno":"ABCDE1234F","address":"12, MG Road","pincode":"302001","statecode":"8","city":"Jaipur","district":"Jaipur"}
Response:
{
    "response": "OK",
    "code": 200,
    "msg": "Petro Card Purchase Successfully.!",
    "reqtype": "petrocardpurchase",
    "reqid": "20260924190310889900",
    "data": {
        "paymentmode": "WALLET",
        "billno": "518342",
        "kitid": 12,
        "kitname": "PETRO CARD SILVER RS. 5000/-",
        "amount": 5000.00,
        "walletbalance": 7500.00
    }
}
Note : paymentmode = WALLET (instant purchase from wallet; wallettype is required) or PG (UPI payment gateway).
Note : For PG, the response contains orderid and paymenturl. Open paymenturl in a WebView; when it reaches PETROCARDPurchase.aspx, close it and call the Payment Status API (ordertype = PETROCARD).
Note : dob format is dd-MMM-yyyy (e.g. 15-Aug-1990). statecode and gender come from the Petro Card Form API.
Note : The server takes the amount from the database. The same request again within 20 seconds returns code 409.
